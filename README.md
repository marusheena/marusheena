## HEROES

Asistente académico con IA para alumnado neurodivergente, diseñado a partir de la investigación con alumnado autista. Adapta el material de clase para que se entienda, acompaña cada tarea paso a paso y reparte el estudio de la evaluación para llegar a la víspera del examen solo con repaso.

**Cómo lo construyo**

- Investigación con 12 participantes (7 familias, 2 profesionales de aula TEA y 3 docentes), contrastada con literatura científica internacional.
- 13 insights, cada uno con sus fuentes y su nivel de confianza. Cada funcionalidad tiene que responder a uno.
- Spec-Driven Development con Spec Kit: Investigación → Insights → PRD → Spec → Plan técnico → Tareas → Código.
- Claude Code trabaja dentro del repositorio y propone cambios por pull request. Yo reviso y apruebo cada uno, y cada decisión queda registrada con su porqué.
- En marcha: el adaptador de enunciados, un prototipo con la API de un LLM que sigue 18 reglas apoyadas en evidencia y se mide con evals.

Estado: discovery terminado, PRD del planificador en curso. El repositorio es privado porque HEROES trata con menores. Si quieres verlo, [escríbeme](mailto:maruxamoreira@gmail.com) y te doy acceso.
